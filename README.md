# Stock Trading Platform

A console-based Stock Trading Platform developed using Java. This project allows users to buy and sell stocks, manage their portfolio, and track transactions.

## Features

- View available stocks and market prices
- Buy stocks
- Sell owned stocks
- View portfolio holdings
- Check available balance
- View transaction history
- Calculate total portfolio value
- Track realized profit and loss
- Input validation and error handling

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- HashMap
- Scanner
- VS Code

## Project Structure

```text
Stock-Trading-Platform/
│
├── Stock.java
├── Portfolio.java
├── StockTradingPlatform.java
└── README.md
```

## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Compile the Java files:

```bash
javac Stock.java Portfolio.java StockTradingPlatform.java
```

4. Run the application:

```bash
java StockTradingPlatform
```
